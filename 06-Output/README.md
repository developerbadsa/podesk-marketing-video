# Output Directory

This directory is reserved exclusively for rendered video exports, preview cuts, and production contact sheets.

## Directory Structure & Expectations

- `final/`: Rendered final master video files (`.mp4`, H.264, 1080x1920, 30 FPS).
- `previews/`: Draft render cuts, scene previews, and staging clips.
- `contact-sheets/`: Visual audit sheets and scene storyboard stills.

## Rules

1. Keep all rendered outputs strictly isolated from the source assets in `01-Voiceover`, `02-Brand-Assets`, `03-Original-App-Screenshots`, and `04-Workflow-Screenshots`.
2. Do not commit heavy intermediate video renders or cache files to version control without approval.
