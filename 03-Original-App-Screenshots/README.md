# Original App Screenshots

This directory contains the authentic, high-resolution original screenshots captured from the PODesk application inside Shopify Admin.

## Inventory of Screenshots

- `01-dashboard.png` (1600x900 PNG): PODesk main dashboard showing stock health metrics, total inventory units, open purchase order value, reorder alerts, stockout risk summary, inventory by location, and quick actions (+ Create PO, Auto-Reorder, Sync).
- `02-reorder-planning.png` (1600x900 PNG): Reorder Planning view showing product variants, inventory quantities, 30-day sales velocity, days until stockout, reorder quantity calculations, buffer days, target stock, supplier filters, and manual override controls.
- `03-supplier-mapping.png` (1600x900 PNG): Supplier Management & SKU Mapping directory showing supplier profiles, contact info, lead time overrides, supplier SKUs, and unit cost mappings.
- `04-stock-import.png` (1600x900 PNG): CSV Stock & Supplier Mapping Import view showing CSV drag-and-drop zone, sample template download links, auto-header mapping, and line-by-line validation preview.
- `05-settings.png` (1600x900 PNG): Store Settings view showing company profile details, purchase order number prefix, currency configuration, notification preferences, email provider selection (SMTP / Resend), and plan usage.

## Critical Production Rules

1. **Source of Truth:** These screenshots represent the authentic PODesk interface. Never recreate, redraw, or use generative AI to fabricate dashboard screens.
2. **Binary Integrity:** Never re-encode, compress, or overwrite these original PNG files.
3. **Framing & Privacy:** The screenshots contain browser chrome and test store data. For the 9:16 vertical video composition, crop out browser navigation and taskbars, and apply non-destructive localized masks over test identifiers (such as dev store URLs). Do not permanently edit the source files.
4. **Note on Product Details:** There is no dedicated Product Details screenshot in this directory. Purchase Order Details is located in `04-Workflow-Screenshots/`.
